# ISAEVA Launcher

A fast custom Roblox launcher built by zekov.

**[Download](https://github.com/zekovdev/isaeva-launcher/releases/latest/download/ISAEVA-Launcher.exe)** · [Releases](https://github.com/zekovdev/isaeva-launcher/releases) · [Discord](https://discord.gg/isaeva)

## Install

Download the EXE and run it. Install 4.8.1 manually once, even if you already installed a preview. After that, the launcher checks for signed updates on startup.

Auto-update can be toggled in **Mods & Updates**. If it is off, the launcher asks before installing anything.

Windows may show a warning because the EXE is not Authenticode-signed yet. ISAEVA still verifies every update with RSA-PSS and SHA-256.
